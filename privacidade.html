Política de privacidade do projeto

Última atualização: 6 de outubro de 2026

Quais dados o app acessa

O projeto acessa somente os dados da conta Google que o próprio usuário autoriza, listados na tela de consentimento do Google no momento da autorização.

Como os dados são usados

Os dados são usados apenas para executar as funções do app pedidas pelo usuário. Eles não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto quando a lei exigir.

Armazenamento

O app guarda os tokens de acesso em servidor protegido, pelo tempo em que a integração estiver ativa. Ao revogar o acesso, os tokens deixam de funcionar e são apagados.

Política de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

Contato

Dúvidas ou pedidos de exclusão de dados: pelo e-mail de suporte exibido na tela de login do Google deste app.
